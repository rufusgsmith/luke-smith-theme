# businesses

A Claude Code mod that puts Luke Smith's ten business logos in a column down the right of the backdrop, over pale grey twisting ribbons.

The backdrop shows in the Claude desktop and mobile apps. The terminal doesn't draw it.

## Install

At the prompt of a terminal Claude Code session:

```
/plugin install businesses --marketplace rufusgsmith/luke-smith-theme
```

Answer `y` to add the marketplace, then press Enter to pick the user scope.

From a shell:

```bash
claude plugin install businesses --marketplace rufusgsmith/luke-smith-theme
```

In the desktop app, where `/plugin` doesn't run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `rufusgsmith/luke-smith-theme`, then **Add plugin**.
